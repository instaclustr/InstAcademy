# InstAcademy

Hands-on labs and example code for **NetApp Instaclustr** learning courses.

InstAcademy is organized by technology, then by course. Each course folder contains Dev Tools lab guides, optional Bruno fast-mode REST collections, and commented Python reference scripts.

## Browse by folder

| Path | What's inside |
|------|----------------|
| [OpenSearch/](OpenSearch/) | OpenSearch courses (vector search, neural pipelines, RAG, production tuning) |
